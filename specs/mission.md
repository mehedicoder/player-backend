# Mission

Build a scalable backend platform for millions of game players.

The platform must support:
- Player registration and login
- Player profile management
- Inventory management
- Wallet and rewards
- Match history
- Leaderboards
- Real-time and asynchronous event processing

The system must be:
- Highly available
- Low latency
- Horizontally scalable
- Secure
- Observable
- Easy to deploy using CI/CD and GitOps

Agents may help with implementation, review, and validation, but the human engineer owns architecture, production safety, and final approval.
